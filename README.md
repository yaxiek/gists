## 名前のルール

- フォルダ名は `YYYYMMDD-<英小文字kebab-case>` です。
  - 例: `20261025-muse-podcast-prompt/`
- 日付は初めて公開した日です。
- 公開後に内容を更新しても、フォルダ名・ファイル名（日付も含む）は変えません。リンク切れを防ぐためです。
- 新しく追加したら、上の一覧に1行追記します（新しいものを上に）。
